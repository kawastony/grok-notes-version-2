# Pathway 1 — bridge hypothesis (not a theorem)

## Statement

\[
\boxed{
a_{\rm eff}(\Sigma_{\rm med})\;\stackrel{?}{=}\;
\frac{1}{Q}\sqrt{G\rho_\Lambda}\,c
\qquad
Q=\sqrt{2}
}
\]

With standard inputs (H_0=70 km/s/Mpc, Ω_Λ=0.7):
\[
\frac{1}{Q}\sqrt{G\rho_\Lambda}\,c \approx 1.390\times 10^{-10}\ {\rm m\,s^{-2}}
\]
vs SPARC median readout \(\simeq 1.41\times 10^{-10}\) → **~1.4%**.

---

## What this is

| Label | Meaning |
|-------|--------|
| Bridge hypothesis | Links galactic a_eff to cosmological ρ_Λ using locked Q |
| Replaces | Hand unit a_*=10^{-10} in a_eff≈Q×10^{-10} |
| Does **not** | Derive a_eff from pure cone action without external scale |
| Compatible with | μ no-go: one dimensionful input (here ρ_Λ) is required |

## How it sits in a_eff = Λ_*^2 μ

One reading (provisional):
\[
\Lambda_*^2\mu \;\stackrel{?}{=}\; \frac{1}{Q}\sqrt{G\rho_\Lambda}\,c
\]
at the median (or as the reference absolute scale), with Σ_b^{1/7} modulation on top as in Paper 24.

That does **not** derive μ; it packages the product Λ_*^2μ as a cosmological–geometric combination.

---

## Pass / fail as a hypothesis

**Support**
- Removes ad hoc 10^{-10} unit.
- Uses only locked Q and standard ρ_Λ.
- ~1% match at Planck-like H_0.

**Fail / weaken**
- Local H_0~73 shifts prediction high by ~3% (still small vs bootstrap on γ).
- No derivation of the factor 1/Q from action variation — it is the geometric lock that fits.
- Imports cosmology; pure-galaxy closure still open.

**Falsification style tests**
1. If preferred galactic a_eff moves far from 1/Q √(Gρ_Λ)c under improved SPARC + cosmology, hypothesis weakens.
2. If a pure-action μ×Λ_*^2 is derived and disagrees, Pathway 1 is demoted to coincidence.

## One-line status

**Candidate normalization principle:** absolute scale bridged by ρ_Λ and Q; not a cone-only theorem; consistent with the μ no-go.
