# Case A — Midpoint ansatz with u = μ

Dimensionally natural: [μ]=L⁻¹, ξ=r, α dimensionless.

---

## Setup

\[
E_\pm(\lambda)=\mu_*\pm\Delta(\lambda),\qquad
M(\lambda)=\mu_*=\text{invariant under }\lambda.
\]

\[
\frac{E_+^2+E_-^2}{2}=\mu_*^2+\Delta^2.
\]

Flow law:
\[
\left.\frac{d\mu}{dr}\right|_*=\alpha\bigl(\mu_*^2+\Delta^2\bigr).
\]

---

## Endpoint pair candidates

| Pair | E₋ | E₊ | λ |
|------|----|----|---|
| Regime | compressive / inner scale | tensile / outer scale | cone phase or radius bin |
| Surface density | low-Σ_b effective scale | high-Σ_b effective scale | Σ_b |
| Lattice | soft-mode gap near core1 | soft-mode gap near core2 | boost / separation |

Best aligned with existing TAFA language: **compressive ↔ tensile** (Paper 25 pause between regimes), with μ_* the invariant pause inverse length.

---

## Small-Δ limit

\[
\left.\frac{d\mu}{dr}\right|_*\approx\alpha\mu_*^2.
\]

Stabilizing α<0 → relaxation toward fixed μ_*.  
If μ_* is set by an external length (r_p from data or UV), this organizes flow; it does not invent μ_* from angles alone.
