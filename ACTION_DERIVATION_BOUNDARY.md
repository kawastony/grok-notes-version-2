# Explicit action derivation — what is possible now

## Available action-level content (Paper 25)

Minimal defect EFT:
\[
\mathcal{L}_{\rm def}=\tfrac12(\partial X)^2+\tfrac12(\partial Y)^2+\frac{g_1}{2}X^2Y+\frac{g_2}{6}Y^3.
\]
RG fixed-point branch g₂=0 gives η_X^*=2ε/13 → Δ_X=24/13 at ε=1.

This is an **effective** Lagrangian for the defect sector, not the full TAFA bulk+brane action.

## What an “explicit action derivation” would require

1. Parent TAFA action (bulk cone metric + topological/axion sector + baryon coupling).
2. Reduction → L_def (integrate out heavy modes, project to mismatch X and mediator Y).
3. Derive cubic g₁ from that reduction (not insert by hand).
4. Derive sourcing X∝Σ_b^{1/n} from baryon–defect coupling variation.
5. Derive O_μ as the response kernel of that action on the junction.
6. Read off μ and a_eff without a free A.

## Explicit partial derivation (RG only)

Given L_def with g₂=0, the β-functions admit the fixed point g₁*²=(4π)³ε(4/13), and
\[
\eta_X^*=\frac{2\varepsilon}{13}+O(\varepsilon^2)\implies\Delta_X=\frac{24}{13}\ (\varepsilon=1).
\]
That is a real (if reduced) derivation. It does **not** by itself produce γ=1/7 without n_eff and Δ_μ from geometry.

## Boundary sentence

**Action derivation is partially explicit at the defect EFT + RG level; the parent TAFA action reduction and the operator→μ→a_eff map remain open.**
